# Asset Credits

Tower Yard uses selected 2D sprites from Kenney asset packs:

- Kenney Brick Pack: https://kenney.nl/assets/brick-pack
- Kenney Block Pack: https://kenney.nl/assets/block-pack
- Kenney Platformer Pack: Industrial: https://kenney.nl/assets/platformer-pack-industrial

License: Creative Commons Zero (CC0), https://creativecommons.org/publicdomain/zero/1.0/

Only the specific construction-themed PNG files used by the game were copied into `TowerYard/Assets.xcassets`. Download archives and unused files are not included in the project.
